# Vendored Apache JMeter compile jars

Compile-only stubs for `grid-sql-jmeter` (JavaSampler API).

| File | Source |
|------|--------|
| `ApacheJMeter_java.jar` | Apache JMeter 5.6.3 `lib/ext/` |
| `ApacheJMeter_core.jar` | Apache JMeter 5.6.3 `lib/ext/` |

License: Apache License 2.0 (same as upstream JMeter).

Runtime load tests still need a full JMeter install (`JMETER_HOME`) — these jars are not a substitute for the GUI/CLI distribution.
